# Interactive DSA Sorting Visualizer 📊

An interactive web-based algorithm visualizer built with **FastAPI** and modern **JavaScript**. This application provides real-time visual step-by-step executions of fundamental sorting algorithms with adjustable speed controls.

## 🚀 Features

* **Multiple Sorting Algorithms**: Visualizations for **Bubble Sort**, **Selection Sort**, and **Insertion Sort**.
* **Real-Time Step Animation**: Dynamic height and CSS color highlights indicating active element comparisons, current minimums, and completed sorted states.
* **Speed Control Slider**: Adjust the execution delay dynamically while the visualizer is running.
* **FastAPI Backend**: Clean and modern Python server serving the frontend.

## 🛠️ Tech Stack

* **Backend**: Python 3, FastAPI, Uvicorn
* **Frontend**: HTML5, CSS3 (Flexbox), JavaScript (Async/Await ES6+)
